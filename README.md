# Dani Pascal Soler - Atletismo de Élite & Experiencia Cinética

Web interactiva de alto impacto para **Dani Pascal Soler**, atleta de élite en pruebas de velocidad (100m, 200m y 400m). Diseñada con un enfoque táctil, biomecánico y **super satisfactorio**.

![Preview](preview.png)

## ⚡ Características Principales

- **Simulador Biomecánico de Zancada a 60 FPS**: Cinemática procedural en tiempo real con estelas aerodinámicas, impacto de clavos sobre tartán y control interactivo de cadencia (SPM) y longitud de zancada.
- **Motor de Audio ASMR Web Audio**: Síntesis de sonido pura (sin archivos de audio externos): tics táctiles, zancada acústica, disparo de tacos de salida y acordes de victoria.
- **Simulador de Reacción en Tacos de Salida**: Test de reflejos interactivo con secuencia reglamentaria (*"A sus puestos... Listos... ¡YA!"*) y detección de salida nula frente a la marca de Dani Pascal (0.118s).
- **Metrónomo & Tap BPM de Zancada**: Calcula el ritmo de carrera en vivo y sincroniza el simulador de carrera.
- **Marcas Personales**: Cronómetro interactivo acelerado en 100m (9.84s), 200m (19.92s) y 400m (44.50s).
- **Medallero 3D Táctil**: Efectos tridimensionales con ráfagas de chispas doradas.
- **Personalizador de Zapatillas de Clavos**: Opciones de placa de carbono reactiva (*Carbon Matrix*, *Titanium Flex*, *Hyper Neon*).
- **Modo Flow State**: Modo de inmersión total con saturación de color y ritmo supersónico.

## 🏃 Cómo Ejecutar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/workspacenil/dani.git
   ```
2. Abre `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari). O ejecuta `abrir_web.bat` en Windows.
